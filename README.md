# Lasder Cumpleaños

Sitio estático para publicar gratis con GitHub Pages.

## Cambiar cumpleaños

Abrí `script.js` y modificá la lista `birthdays`. No se utiliza el año de nacimiento.

## Publicar

Subí estos archivos a la rama principal de un repositorio. En GitHub, entrá a **Settings → Pages**, elegí **Deploy from a branch**, seleccioná la rama `main` y la carpeta raíz.
